# MAP (My Asset Preset)

인디 게임 개발자가 에셋마다 어떤 도구를 쓸지 견적을 받아 비교하는 서비스다.

## 폴더

| 위치 | 내용 |
|---|---|
| `src/js/` | 화면과 견적 엔진. 파일 이름 순서대로 하나의 스크립트로 묶인다 |
| `src/style.css`, `src/shell-*.html` | 스타일과 페이지 뼈대 |
| `build.mjs` | `dist/index.html`, `dist/admin.html`을 만든다 |
| `data/` | 도구 기준 데이터와 기준 프롬프트(사람이 고치는 원본) |
| `supabase/` | 데이터베이스 구조, 시작 데이터, 저장소 설정, AI 도우미 서버 함수 |
| `admin/` | 운영 화면(가격·약관 확인, 변경 소식 등록, 결과물 검토) |
| `test/` | 자동 검사 |
| `docs/` | 직접 하실 일, 가격·약관 확인 목록, 기준 프롬프트 |

## 명령

```
npm install              # 검사에 쓰는 도구 설치
node build.mjs           # dist/index.html 만들기
npm test                 # 견적 엔진 검사 + 데이터베이스 규칙 검사
node test/ui-smoke.cjs 1440 900 d   # 화면 전체 흐름 검사(Playwright 필요)
node test/ai-assist.cjs  # AI 도우미 연결 검사(가짜 서버 사용)
node tools-seed.mjs      # data/*.json → supabase/seed.sql
```

## 소스 파일

| 파일 | 내용 |
|---|---|
| `01-data.js` | 도구, 요금제, 장르, 그림체 같은 기준 데이터 |
| `02-sample-data.js` | 커뮤니티 예시 데이터 |
| `03-state.js`, `04-util.js` | 화면 상태와 공통 함수 |
| `05-engine.js` | 견적 엔진: 에셋 줄 만들기, 비용 계산, 견적 세 가지 고르기 |
| `07-game-calc.js` | 작업 기록과 스토어 AI 고지문 계산 |
| `08`~`10`, `13`~`15`, `17` | 화면(홈, 커뮤니티, 새 견적, 견적 비교, 저장한 게임) |
| `11-chat-edit.js`, `16-chat-request.js` | 말로 고치기(규칙 해석) |
| `16b-ai-assist.js` | AI 도우미 연결. 설정이 없으면 동작하지 않는다 |
| `18`~`20`, `99-boot.js` | 창, 그리기, 이벤트, 시작 |

파일들은 한 함수 범위 안에서 이어 붙으므로 다른 파일의 함수를 그대로 부를 수 있다. 대신 같은 이름을 두 번 선언하지 않도록 주의한다.

## 지금 상태

- 서버 없이도 `dist/index.html` 하나로 시안처럼 동작한다. 데이터는 브라우저 안에 저장된다.
- 데이터베이스 구조와 토큰 규칙은 내장 Postgres로 검사했다. 실제 Supabase 프로젝트에서는 아직 실행해 보지 않았다.
- 화면의 저장·커뮤니티 기능은 아직 서버에 연결되어 있지 않다. Supabase 프로젝트가 생기면 연결한다.
- AI 도우미는 화면 쪽 연결과 서버 함수 코드가 있고, 가짜 서버로 검사했다. 실제 AI 호출은 키를 넣은 뒤 확인한다.
