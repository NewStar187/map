# 가격·약관 확인 목록

조사한 날은 2026년 11월 10일이다. 각 도구의 공식 페이지를 요약해 읽은 1차 조사이므로, 서비스에 싣기 전에 아래 항목을 사람이 원문에서 확인한다. 확인을 마친 값은 `data/tools.json`에 반영하고 `node tools-seed.mjs`를 실행한다.

시안에 들어 있던 가격은 이번 조사 결과와 모두 일치한다. 조사에서 새로 확인된 상위 요금제(PixelLab Pixel Architect, Meshy Premium·Ultra, ElevenLabs Pro, GitHub Copilot Max)와 Retro Diffusion 웹 버전은 `data/tools.json`에만 들어 있고 화면에는 아직 없다.

- 상업적 이용 요약: 공식 가격·약관 페이지가 열리지 않았다. 외부 자료는 무료 플랜이 비상업용이고 유료 플랜에 상업적 이용 허락이 포함된다고 적는다.
- 가격: https://stableaudio.com/pricing
- 약관: https://stability.ai/license
- 가격이 추정값인 요금제: 무료, Creator, Pro
- [ ] 지금의 요금제 이름과 가격, 요금제별 상업적 이용 조건을 공식 페이지에서 확인할 것

### AIVA
- 조사 상태: 확인(가격은 유로, 연간 결제 기준)
- 상업적 이용 요약: Pro 요금제만 저작권이 사용자에게 있고 제한 없이 수익화할 수 있다. Standard는 유튜브·트위치 같은 곳에서만 수익화할 수 있어 판매하는 게임에는 맞지 않고, 무료 플랜은 수익화할 수 없다.
- 가격: https://www.aiva.ai/pricing
- 약관: https://www.aiva.ai/legal/1
- 가격이 추정값인 요금제: Standard, Pro
- [ ] 가격이 유로와 연간 결제 기준으로만 나온다. 월 결제 가격과 달러 가격 확인(지금 값은 유로를 달러로 어림한 것)

- 가격: https://freesound.org

- 가격: https://cursor.com/pricing
- 약관: https://cursor.com/terms-of-service

- 조사 상태: 확인

- 가격: https://opengameart.org
- 약관: https://opengameart.org/content/faq
- 확인할 것 없음

## 스토어 규정

### 스팀
- 개발 중에 AI 서비스를 썼거나 게임이 AI 서비스를 포함하면 콘텐츠 설문에 밝혀야 하고, 내용은 상점 페이지에 공개된다. 미리 만든 콘텐츠와 실행 중에 만드는 콘텐츠를 나눠 묻고, 실행 중 생성은 어떤 안전장치를 두는지도 적어야 한다. 설문은 "이런 도구로 얻는 효율 향상은 이 항목의 초점이 아니다"라고 적어, 플레이어가 접하는 콘텐츠(그림·소리·이야기·번역)를 대상으로 본다.
- 근거: https://partner.steamgames.com/doc/gettingstarted/contentsurvey
- [ ] AI가 짠 코드가 고지 대상이 아니라고 공식 문서가 명시하지는 않는다. 시안은 "그대로 들어간 AI 코드는 밝히는 쪽"으로 정해 두었으니 이 판단을 유지할지 팀이 결정

### itch.io
- 생성형 AI로 만든 자료가 들어 있으면 프로젝트 편집 화면의 AI 공개 항목에 표시해야 한다. 에셋 제작자는 필수, 게임은 권장. 분야는 그림, 소리, 글·대사, 코드. 전통적인 게임 AI나 절차적 생성은 해당하지 않는다.
- 근거: https://itch.io/docs/creators/quality-guidelines

## 조사 방법의 한계

- 페이지를 직접 읽은 것이 아니라 요약해 읽는 도구를 거쳤다. 따옴표 안의 문구는 요약에 실린 대로이며, 법적으로 민감한 문장은 원문을 다시 확인한다.
- PixelLab 가격 페이지, Midjourney 도움말의 요금 페이지, Aseprite 결제 화면은 열리지 않았다.
- 연간 결제 가격은 대부분 확인하지 못했다. 견적은 월 결제 가격으로 계산한다.
