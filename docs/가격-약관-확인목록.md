# 가격·약관 확인 목록

조사한 날은 2026년 11월 10일이다. 각 도구의 공식 페이지를 요약해 읽은 1차 조사이므로, 서비스에 싣기 전에 아래 항목을 사람이 원문에서 확인한다. 확인을 마친 값은 `data/tools.json`에 반영하고 `node tools-seed.mjs`를 실행한다.

시안에 들어 있던 가격은 이번 조사 결과와 모두 일치한다. 조사에서 새로 확인된 상위 요금제(PixelLab Pixel Architect, Meshy Premium·Ultra, ElevenLabs Pro, GitHub Copilot Max)와 Retro Diffusion 웹 버전은 `data/tools.json`에만 들어 있고 화면에는 아직 없다.

## 도구별 확인할 것

### PixelLab
- 조사 상태: 약관 확인, 가격은 외부 자료
- 상업적 이용 요약: 약관이 요금제를 나누지 않고 상업적 이용을 허락하고, 저작권도 사용자에게 있다고 적는다. 결과물로 다른 AI를 학습시키는 것은 서면 허락 없이는 금지.
- 약관에 적힌 날짜: 2026-10-30
- 가격: https://www.pixellab.ai/pricing
- 약관: https://www.pixellab.ai/termsofservice
- 가격이 추정값인 요금제: Pixel Apprentice, Pixel Artisan, Pixel Architect
- [ ] 공식 가격 페이지가 읽히지 않아 가격은 외부 자료 두 곳 기준이다. 로그인해서 실제 가격과 연간 결제 가격을 확인할 것
- [ ] 무료 체험 한도 확인

### Retro Diffusion
- 조사 상태: 웹 가격·FAQ 확인, 확장의 권리는 개발자 댓글
- 상업적 이용 요약: 웹 버전 FAQ는 결과물이 사용자 소유이고 상업 프로젝트에 쓸 수 있다고 적는다. Aseprite 확장도 결과물은 만든 사람 소유라고 개발자가 답했다(확장의 코드와 모델 자체는 상업 이용 불가).
- 가격: https://astropulse.itch.io/retrodiffusion
- 약관: https://www.retrodiffusion.ai
- [ ] 확장 안에 든 라이선스 파일을 직접 읽을 것
- [ ] 이용약관 본문과 날짜 확인

### Z-Image
- 조사 상태: 확인
- 상업적 이용 요약: Apache-2.0 라이선스. 상업적 이용이 가능하고 결과물에 대한 권리 주장도 없다.
- 가격: https://github.com/Tongyi-MAI/Z-Image
- 약관: https://github.com/Tongyi-MAI/Z-Image/blob/main/LICENSE
- [ ] 공식 안내는 Turbo 모델이 그래픽카드 메모리 16GB에서 무리 없이 돈다는 것뿐이다. 8GB에서 도는지는 직접 확인할 것(시안은 8GB 이상으로 안내 중)

### Unity AI
- 조사 상태: 가격·상업 이용 확인, 소유권 문구는 미확인

- 약관에 적힌 날짜: 2026-07-28
- 가격: https://unity.com/products/compare-plans
- 약관: https://unity.com/legal/third-party-ai-terms
- [ ] 결과물 소유권 문구 확인(Unity AI 약관 페이지가 열리지 않았음)
- [ ] 생성 한 번에 드는 크레딧 수 공식 표 확인

## 스토어 규정

### 스팀
- 개발 중에 AI 서비스를 썼거나 게임이 AI 서비스를 포함하면 콘텐츠 설문에 밝혀야 하고, 내용은 상점 페이지에 공개된다. 미리 만든 콘텐츠와 실행 중에 만드는 콘텐츠를 나눠 묻고, 실행 중 생성은 어떤 안전장치를 두는지도 적어야 한다. 설문은 "이런 도구로 얻는 효율 향상은 이 항목의 초점이 아니다"라고 적어, 플레이어가 접하는 콘텐츠(그림·소리·이야기·번역)를 대상으로 본다.
- 근거: https://partner.steamgames.com/doc/gettingstarted/contentsurvey
- [ ] AI가 짠 코드가 고지 대상이 아니라고 공식 문서가 명시하지는 않는다. 시안은 "그대로 들어간 AI 코드는 밝히는 쪽"으로 정해 두었으니 이 판단을 유지할지 팀이 결정

### itch.io
- 생성형 AI로 만든 자료가 들어 있으면 프로젝트 편집 화면의 AI 공개 항목에 표시해야 한다. 에셋 제작자는 필수, 게임은 권장. 분야는 그림, 소리, 글·대사, 코드. 전통적인 게임 AI나 절차적 생성은 해당하지 않는다.
- 근거: https://itch.io/docs/creators/quality-guidelines

## 조사 방법의 한계

- 페이지를 직접 읽은 것이 아니라 요약해 읽는 도구를 거쳤다. 따옴표 안의 문구는 요약에 실린 대로이며, 법적으로 민감한 문장은 원문을 다시 확인한다.
- PixelLab 가격 페이지, Midjourney 도움말의 요금 페이지, Aseprite 결제 화면은 열리지 않았다.
- 연간 결제 가격은 대부분 확인하지 못했다. 견적은 월 결제 가격으로 계산한다.
